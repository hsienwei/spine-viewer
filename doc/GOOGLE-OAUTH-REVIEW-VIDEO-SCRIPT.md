# Google OAuth Review Video Script

Target length: about 60 seconds.

## Required Visual Flow

1. Open Spine Viewer and show the app name.
2. Click Drive.
3. Show the Google OAuth consent screen in English.
4. Grant Google Drive read-only access.
5. Browse folders in the in-app Google Drive browser.
6. Select the related Spine asset files.
7. Load and preview the Spine animation.
8. Open the Share panel.
9. Click Create Share Link.
10. Show the confirmation dialog explaining that selected assets will be uploaded to Spine Viewer storage for a 24-hour preview link.
11. Confirm and show the generated share link.

## English Voiceover

This is Spine Viewer, a web tool for loading and previewing Spine animation assets.

The app uses Google Drive read-only access so users can browse folders inside the app, locate related Spine asset files, and load them together as one asset bundle.

Here, the user grants Google Drive read-only permission. The app does not create, modify, delete, move, rename, or change sharing permissions for any Google Drive files.

After authorization, the user browses Drive folders, selects the related skeleton, atlas, and texture files, and loads them into the viewer.

The selected files are parsed and rendered in the browser for preview.

The app also includes an optional sharing feature. When the user chooses to create a share link, the app shows a confirmation explaining that the selected Spine assets will be uploaded to Spine Viewer storage to create a 24-hour preview link.

This sharing upload is separate from Google Drive access. It does not modify Google Drive files or change Google Drive permissions. The uploaded files are used only to provide the shareable Spine Viewer preview link.

## Short Version

This is Spine Viewer, a web tool for loading and previewing Spine animation assets.

The app uses Google Drive read-only access so users can browse folders inside the app, select related Spine asset files, and load them together for preview.

The app does not create, modify, delete, move, rename, or change sharing permissions for any Google Drive files.

After previewing the asset, the user may optionally create a share link. The app asks for confirmation before uploading the selected Spine assets to Spine Viewer storage to generate a 24-hour preview link.

This upload is separate from Google Drive access and is used only to provide the shareable preview.

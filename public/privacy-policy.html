Privacy Policy

Spine Viewer 隱私權政策 / Privacy Policy

This page explains how Spine Viewer handles Google Drive data, selected Spine asset files, optional share uploads, and private data protection measures.

Effective Date: June 1, 2026

1. 服務範圍 / Service Scope

繁體中文

Spine Viewer 是由 hsienwei 維護的網頁工具，用於載入、預覽、播放與檢視 Spine 動畫資產。你可以從本機檔案或 Google Drive 選取 Spine 資產檔案。

English

Spine Viewer is a web tool maintained by hsienwei for loading, previewing, playing, and inspecting Spine animation assets. You may select Spine asset files from local storage or Google Drive.

2. Google 使用者資料 / Google User Data

繁體中文
  • 本服務目前請求 `https://www.googleapis.com/auth/drive.file`。
  • 此權限搭配 Google Picker 使用，讓你選取 Spine 檔案，並只下載你在 picker 中明確選擇的檔案。
  • 本服務不會建立、修改、刪除、搬移、重新命名或變更任何 Google Drive 檔案權限。
English
  • The service currently requests `https://www.googleapis.com/auth/drive.file`.
  • This scope is used with Google Picker to let you select Spine files and to download only the files you explicitly choose in the picker.
  • The service does not create, modify, delete, move, rename, or change permissions for any Google Drive files.

3. 資料用途 / Data Use

繁體中文
  • 顯示 Google Picker 並接收你明確選擇的檔案。
  • 讀取你選取的 `.json`、`.skel`、`.atlas` 與貼圖檔案，用於解析、分組、預覽與播放 Spine 動畫。
  • OAuth access token 僅用於目前工作階段向 Google Drive API 發送請求。
English
  • To show Google Picker and receive the files you explicitly choose.
  • To read selected `.json`, `.skel`, `.atlas`, and texture files for parsing, grouping, previewing, and playing Spine animations.
  • OAuth access tokens are used only to send Google Drive API requests during the current session.

4. 分享上傳 / Share Uploads

繁體中文
  • 你可以只在瀏覽器中本機預覽檔案，而不使用分享功能。
  • 當你按下建立分享連結並確認後，本服務會將目前選取的 Spine 資產檔案上傳到本服務的儲存空間，以產生 24 小時有效的預覽連結。
  • 分享上傳是獨立的使用者主動操作，不會修改 Google Drive 檔案，也不會變更 Google Drive 分享權限。
  • 分享功能可能會依你的選項處理檔案，例如將貼圖轉為 WebP、加入浮水印，或只保留目前動畫。
English
  • You may preview files locally in the browser without using the sharing feature.
  • When you choose Create Share Link and confirm, the service uploads the currently selected Spine asset files to the service storage to create a 24-hour preview link.
  • Share upload is a separate user-initiated action. It does not modify Google Drive files or change Google Drive sharing permissions.
  • The sharing feature may process files according to your options, such as converting textures to WebP, applying a watermark, or keeping only the current animation.

5. 私密資料保護機制 / Private Data Protection Measures

繁體中文
  • 所有網站、Google API 與分享 API 請求均透過 HTTPS 傳輸，以保護傳輸中的資料。
  • Google OAuth access token 僅保留在瀏覽器記憶體中，用於目前工作階段；本服務不會將 OAuth token 寫入 localStorage、分享儲存空間或自有資料庫。
  • Google Drive 權限採唯讀用途，僅在使用者透過 Google Picker 選取或下載已選檔案時發送請求。
  • 分享檔案儲存在非公開的服務儲存空間；分享連結不會直接暴露底層儲存物件 URL。
  • 分享預覽必須透過隨機產生的分享 token 存取，服務端會在讀取 manifest 或檔案物件前驗證 token 是否存在、未過期且未撤銷。
  • 分享 token 預設 24 小時後失效，使用者也可在分享紀錄中撤銷分享連結。
  • 服務端只會透過受控的分享 API 讀取分享檔案，不提供公開目錄瀏覽或未授權的檔案清單查詢。
  • 瀏覽器 localStorage 僅用於介面偏好、Google Drive 導覽狀態與分享紀錄，不儲存 Google OAuth token 或 Google Drive 檔案內容。
  • 本服務不會販售 Google 使用者資料，也不會提供給廣告平台、資料仲介或資訊轉售方。
English
  • All website, Google API, and sharing API requests are transmitted over HTTPS to protect data in transit.
  • Google OAuth access tokens are kept only in browser memory for the current session. The service does not write OAuth tokens to localStorage, share storage, or a first-party database.
  • Google Drive access is used in a read-only manner and only when the user selects or downloads chosen files through Google Picker.
  • Shared files are stored in private service storage. Share links do not expose direct underlying storage object URLs.
  • Shared previews require a randomly generated share token. The service validates that the token exists, has not expired, and has not been revoked before returning manifests or file objects.
  • Share tokens expire after 24 hours by default, and users may revoke share links from share history.
  • The server reads shared files only through controlled sharing APIs. It does not provide public directory browsing or unauthenticated file listing.
  • Browser localStorage is used only for interface preferences and share history. It does not store Google OAuth tokens or Google Drive file contents.
  • The service does not sell Google user data or provide it to advertising platforms, data brokers, or information resellers.

6. 保留與刪除 / Retention and Deletion

繁體中文
  • 未分享的檔案內容主要在瀏覽器工作階段中處理。
  • 分享連結預設 24 小時後到期；到期或撤銷後，分享預覽將不可用。
  • 介面偏好、Google Drive 導覽狀態與分享紀錄可能保存在瀏覽器 `localStorage`。
  • 你可以清除網站資料、撤銷 Google 授權，或使用分享紀錄中的撤銷功能來移除後續存取能力。
English
  • Files that are not shared are primarily processed during the browser session.
  • Share links expire after 24 hours by default; after expiration or revocation, the shared preview becomes unavailable.
  • Interface preferences and share history may be stored in browser `localStorage`.
  • You may clear site data, revoke Google access, or use share history revocation to remove future access capability.

7. 分享與第三方 / Sharing and Third Parties

繁體中文
  • 本服務不會販售 Google 使用者資料，也不會提供給廣告平台、資料仲介或資訊轉售方。
  • Google Drive 資料僅用於產品中可見的 Google Picker 選檔、檔案載入、預覽與使用者確認後的分享流程。
  • 除 Google API、服務儲存、法律遵循、資安處理或你的明確請求所必要者外，本服務不會揭露相關資料。
  • 本服務對 Google 使用者資料的使用符合 Google API Services User Data Policy，包括 Limited Use 要求。
  • 本服務不會將 Google 使用者資料用於廣告投放、重新定向廣告、信用或貸款評估、使用者監控，或訓練、改善、建立 AI/ML 模型。
English
  • The service does not sell Google user data or provide it to advertising platforms, data brokers, or information resellers.
  • Google Drive data is used only for visible product features: selecting files through Google Picker, loading files, previewing assets, and user-confirmed sharing.
  • Relevant data is disclosed only as necessary for Google APIs, service storage, legal compliance, security handling, or your explicit request.
  • The service's use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements.
  • The service does not use Google user data for advertising, retargeting, credit or lending evaluation, user surveillance, or training, improving, or building AI/ML models.
